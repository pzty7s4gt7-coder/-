# 白室十日 ―篠澤広と、解けない部屋―

学園アイドルマスター・篠澤広の二次創作ノベルゲーム／脱出ゲーム（試作版）です。
気がつくと白い密室に閉じ込められていたプロデューサーと広が、十日間で十の部屋を抜け出します。

`index.html` をブラウザで開くだけで動きます（ビルド不要・外部ライブラリなし）。

## 遊び方

- 1日の流れ：**朝（ノベル）→ 謎解き → 休息区画の夜イベント（ノベル・選択肢）→ 1日の結果**
- 謎解き：部屋の中の気になる場所をクリックして調べる。持ち物は選んでから、使いたい場所をクリックする。
  - 「調べる場所」：クリックできる場所を光らせる
  - 「手帳」：開けた扉の答え、扉の裏の文字、書き留めたメモ
  - 「広に聞く」：ヒント（1部屋3段階）。広の反応つき
  - 広をクリックすると話しかけられる（部屋によっては、それが謎解きの鍵になることも）
- 入力パネルはキーボードでも入力できる（数字・英字、Enter で決定、Backspace で消す）

## 好感度と3つのエンディング

- 夜イベントの選択肢で「広との距離」が縮まる（1日最大10、10日で100）。
- **1日ごとに上限がある。** 扉の前で間違えるたびに −2、ヒント1回につき −1（最低2）。
  上限を超えた分は「今日は、これ以上近づけない」になる。
- 最終的な距離で分岐：
  - **TRUE END「ふたりで解く」**：70以上
  - **NORMAL END「白紙のまま」**：40以上
  - **BAD END「観察対象」**：40未満（広に十日間の失態を淡々と総評される）
- 選択肢の並び順は毎回シャッフルされる。

### シナリオの書き方（scenario.js）

```
広「……おはよう、プロデューサー」   ← 台詞（話者：広 / P / ハク / ？？？）
目を開けると、白があった。             ← 地の文
（……心の声）                          ← 心の声
@bg room night    @show center    @face blush    @hide
@day 3            @puzzle 3       @dayend        @ending
@choice
> 「怖いよ。正直に言うと」 | n1a | 5    ← 文 | 飛び先ラベル | 好感度
*n1a
@if dmiss==0 perfect      ← 今日ノーミスなら perfect へ（aff / miss / hint / gain / flag:名前 も使える）
@set flagname             @jump label     @goto day2
```

### 謎の追加（rooms.js）

各部屋は `hotspots`（x, y, w, h は背景画像に対する%）と `locks`（`digits` / `alpha` / `kana` / `seq` / `clock`）で定義します。
`act(g)` の `g` から `g.say()`, `g.give()`, `g.doc()`, `g.lock()`, `g.miss()`, `g.clear()` などを呼べます。

# 金魚水槽 (Kingyo Suisō)

> 同じリポジトリに、ドット絵のうさぎ観察ゲーム [うさぎのにわ](usagi/) もあります（`usagi/index.html`）。

スマホでもPCでも遊べる、ブラウザで動く3D金魚水槽シミュレータです。
`index.html` をブラウザで開くだけで動きます（Three.js r128 を CDN から読み込みます）。

## できること

- **観る**: タップでガラスをノックすると金魚が驚いて逃げます。長押しすると指のそばに寄ってきます。
- **餌**: タップした場所に餌を落とします。なぞると続けて撒けます。フレーク（しばらく浮いてからひらひら沈む）と沈下粒を選べます。金魚は吸い込むように餌を食べ、底に落ちた餌もついばみます。
- **きらきら**: 宝石・ビー玉・星・真珠・ハート・ラメを落とせます。水中を沈み、底や岩、ほかの物とぶつかって転がり、光を受けてきらめきます。
- **泡**: タップで泡、長押しで泡を出し続けます。エアストーンからも常に泡が上がり、水面で弾けて波紋が広がります。
- **金魚**: 品種（琉金・オランダ・出目金・和金・コメット）と色柄（赤・更紗・三色・黒・丹頂・桜・黄金・白）を1匹ずつ変更、追加（最大12匹）、放流できます。
- **光**: 朝・昼・夕・夜のライティング。光の筋、エアレーション、水中の粒子のオン/オフ。

設定と金魚の顔ぶれはブラウザに保存されます。

## しくみ

- 金魚の体は断面プロファイルから生成した3Dメッシュで、背骨に沿った進行波で毎フレーム変形させています。尾びれ・背びれ・胸びれ・腹びれ・尻びれは個別に形を計算し、泳ぐ速さや旋回、ホバリングに合わせてなびきます。
- 泳ぎは「体の向きを変えて前に進む」操舵モデルです。巡航・ホバリング・底をついばむ・餌を追う・驚いて逃げる、を切り替えながら壁・岩・仲間を避けます。
- 鱗・模様・ひれの条はすべてコード内で描いたテクスチャです。
- 水底・岩・水草にはコースティクス（揺らめく光の網目）と、金魚や物体の影を落としています。
- 端末の描画速度に合わせて解像度を自動調整します。

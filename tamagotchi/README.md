# たまみーつ（たまごっちみーつ ファンメイド再現・仮実装）

`index.html` をブラウザで開くだけで遊べます（スマホ対応・ビルド不要・オフライン可）。
ドット絵はすべて文字列で手打ちしたピクセルパーフェクトなスプライトです。

## あそびかた
- **A**: えらぶ / **B**: けってい / **C**: もどる（画面タッチでも操作できます）
- キーボード: ← / Z = A、Enter / X = B、Esc / C = C
- ペットをタッチすると「なでる」

メニュー: ステータス・ごはん（ごはん8種/おやつ9種）・トイレ（おそうじ）・おふろ・でんき・おくすり・おもちゃ（6種）・あそぶ（どっちむくかな？）・おでかけ（4か所）・もようがえ（5部屋）・かけいず・ずかん

## 遺伝
見た目は **いろ / め / あたま / からだ / せなか** の5パーツで構成され、交配すると
各パーツが父か母のどちらかから 50% ずつ遺伝します（4% で突然変異）。
おでかけ先で出会ったキャラと「おみあい」→ 成功で結婚 → たまごが生まれて次の世代へ。

## デバッグモード
画面下の「デバッグ」ボタン: 時間の速さ変更、即成長、ステータス操作、今のキャラ/相手の遺伝子を直接編集、
子どもを12回シミュレート（A/B/変 で遺伝元を表示）、いつでも結婚、おみあい必ず成功。

## コンテンツの追加
新しい `js/data/*.js` を作って `index.html` に `<script>` を1行足すだけです。

```js
// 頭パーツ（左半分だけ書くと自動で左右反転）
TM.register('head', { id: 'tiara', name: 'ティアラ', spr: TM.spr([...], { mirror: true }), eyeY: 9, mouthY: 15, gap: 6 });
TM.register('eyes', ...)  TM.register('body', ...)  TM.register('back', ...)  TM.register('color', ...)
TM.register('food', ...)  TM.register('toy', ...)   TM.register('furniture', ...)  TM.register('room', ...)
TM.register('place', ...) TM.register('character', ...)  TM.register('icon', ...)
```

ドット絵の文字: `.`=透明、`o a b c d e`=色の遺伝子（輪郭/メイン/影/ハイライト/アクセント/アクセント影）、
それ以外は `js/core/pixel.js` の固定パレット。`tools/preview.html` で全パーツを一覧確認できます。

## 構成
- `js/core/` 描画エンジン（スプライト・色替えキャッシュ・ドットフォント）
- `js/data/` 手打ちドット絵とコンテンツ定義
- `js/game/` 合成（look）・遺伝・状態/時間経過/セーブ・エンジン・デバッグ
- `js/scenes/` 各画面
- `fonts/` DotGothic16（SIL OFL 1.1）

※ 非公式のファンメイド作品です。

## スマホで遊ぶ
`node tamagotchi/tools/build.js` で1ファイル版 `tamagotchi/dist/tamamiitsu.html` を作れます（公開用）。

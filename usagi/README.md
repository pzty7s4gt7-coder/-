# うさぎのにわ (Usagi no Niwa)

スマホ向けの、ずっと眺めていられるうさぎの庭です。
`usagi/index.html` をブラウザで開くだけで動きます（ビルド不要・外部ライブラリなし）。

すべてがドット絵です。うさぎ・にんじん・草花・UIアイコン・カタカナのドットフォントまで、
画像ファイルを使わず、コードの中に1文字＝1ピクセルで手打ちしています。

## あそびかた

- うさぎは自分で動きまわります。ぴょんぴょん跳ねる、毛づくろい、キョロキョロ（立ち上がり）、
  クンクン、穴掘り、のびー、ゴローン（寝転び）、マッタリ（香箱）、ビンキー（ジャンプしてひねる）、
  ダッシュ、ちょうちょを見つめる、ボール遊び、夜は眠って Zzz…
- 一定時間ごとに **にんじん** が生えて育ちます。育つとうさぎが駆け寄って引っこ抜き、モグモグ食べます。
- **うさぎをタップ / 長押し**: なでる（ハートが出ます）。眠っているときは2回つつくと起きます。
- **草をタップ**: うさぎが気づいて寄ってきます。
- **ボール**: ドラッグして投げられます。タップで蹴飛ばせます。うさぎも鼻で転がします。

### ボタン

| ボタン | 動作 |
| --- | --- |
| ウエル | タップした場所ににんじんを植える |
| ボール | ボールを出す / しまう |
| ハヤイ / リアル | 時間の流れ（1日16分 / 端末の時計） |
| カクス | UIを隠す。**ダブルタップ**で戻ります |

PCではキーボードも使えます: `H` UI切替 / `C` にんじん / `B` ボール / `T` 時間 / `N` 1時間進める / `F` おなかペコペコ

## しくみ

- **パーフェクトピクセル**: 画面の短辺が約128ドットになる小さなバッファに描き、
  それを**整数倍**・スムージング無しで全画面に拡大しています。すべてのドットが同じ大きさの正方形になります。
- **スプライト**: `js/art/*.js` に文字列で手打ち。文字 → 色は `js/palette.js`。
  `dev/sprites.html` を開くと全スプライトとフォントを一覧できます。
- **ドットフォント**: `js/font.js`。カタカナ 5×5、英数字 3×5。濁点・半濁点は合成。ひらがなを渡すとカタカナで表示されます。
- **うさぎのAI**: `js/rabbit.js`。行動はジェネレーター（`yield 秒数`）で書いたコルーチンで、
  空腹・眠気・機嫌の3つの欲求と時間帯から重み付きで次の行動を選びます。
- **物理**: `js/physics.js`。高さ(z)つきの2.5D円形ボディ（重力・バウンド・摩擦・壁・ボディ同士の衝突）。
  うさぎは「押すけど押されない」キネマティックボディです。
- **昼夜**: 時刻に応じた色を乗算で重ね、夜はホタルが光ります。昼はちょうちょが飛びます。
- 状態（うさぎの欲求・畑・時刻・設定）は localStorage に保存されます。

## 拡張のしかた

- **アイテム / 遊具を増やす**: `js/entities/ball.js` がひな形です。
  `U.physics.makeBody()` でボディを作り、`update / draw / drawShadow` を持つオブジェクトを `U.world.add()` します。
  描画は `y - z` に、影は `y` に。`sortY` を指定すると大きな遊具の前後関係も調整できます。
- **うさぎの行動を増やす**: `rabbit.js` に `R.myThing = function* () { ... }` を書き、`decide()` の重みリストに追加します。
- **スプライトを増やす**: `js/art/` に文字列で描いて `U.spr()` で登録。新しい色は `palette.js` に1文字を割り当てます。
